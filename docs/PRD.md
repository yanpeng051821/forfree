# 货记：市场看货助手 · MVP PRD

状态：试用版范围；2026-10-02。用户已授权从 PRD、交互结构、开发到测试推进，视觉采用简洁默认方案。

## 问题与用户

面向在义乌等市场选品的外贸人员。照片、语音输入后的文字、供应商信息分散，回到办公室需要再次录入 Excel。目标是现场只记录一次，回去确认后即可导出。

## 主要流程

创建看货任务 → 选择或填写供应商 → 为一件商品拍摄多张照片 → 使用手机输入法输入整段描述 → 整理字段 → 确认、修改并保存 → 按任务筛选、导出带图片的 Excel。

## 必须交付

- 手机优先网页，电脑也能整理记录。
- 看货任务创建、切换；供应商在同一任务中可以复用。
- 商品录入：名称、颜色、材质、尺寸、单件重量(g)、单价、币种、起订量、每箱数量、供应商、原始描述、备注、多张照片。
- 起订量与每箱数量分开；单件重量不从整箱重量推断。未知字段留空，不从商品外观猜尺寸、价格或重量。
- 保存商品前可编辑；支持修改和删除记录。
- 搜索商品、供应商或描述；全部、待补充、已确认过滤。
- 基础文字整理不需要凭据；可选服务端模型接口支持图片与文字整理。界面明确区分两种能力，不把规则处理标成模型识别。
- 本地浏览器保留未提交的采集草稿和图片；上传/识别失败时不清空输入，允许重试。
- SQLite 保存任务、记录和照片归属；图片持久化到本地数据目录。
- Excel 导出每件商品一行，包含首图、照片数量、字段、供应商、原始描述和备注。完整图片在 App 中查看。
- 手动载入的模拟示例任务，显著标明模拟数据，不自动混入真实任务。

## 第一版边界

单个受信任团队在本地或受控环境试用；不包含账号认证、团队权限、支付、客户 CRM、订单、报关、生产部署或 App 商店上架。不能直接暴露给公网。SQLite/本地图片是当前试用版部署选择；多实例正式部署再迁移数据库与对象存储。

浏览器草稿不是完整离线同步：离线可保留输入，保存到服务端、整理与导出需要联网。手机相机与本地持久化需要 HTTPS 或受信任的本地开发环境。

不开发独立录音转写，不引入 Agent；复用手机输入法。

## 数据和准确性

每个商品属于一个任务；同一商品的照片共用记录 ID。保留原始输入。价格与重量必须有文字/标签依据；重量统一到克，但只有明确的单件单位才换算。币种默认人民币，可切换；未经明确标记的整理结果需要用户确认。模型不能补猜未知信息。

## 验收

1. 创建任务后可录入多图商品，刷新页面后记录、图片和供应商均保留。
2. “杯子，红白两色，12元一个，100个起订，单个300克，每箱24个”得到明确字段；缺失的材质、尺寸留空。
3. “整箱重10公斤，每箱24个”不能被填到单件重量；起订量不误填24。
4. 修改、删除、搜索和状态筛选有效，任务间数据隔离。
5. 刷新未提交表单可以恢复文字和照片草稿，网络失败后仍能修改并重试。
6. 导出当前任务 XLSX，字段、中文、数字和图片可用；删除后的记录不会导出。
7. 配置缺失时基础功能完整；外部模型超时、非成功响应、无效结构均给出可恢复错误。
8. 构建、类型检查、真实 API 与手机尺寸浏览器流程测试完成。

## 待真实用户验证

真实 Excel 列顺序、供应商联系方式的采集方式、尺寸/包装单位、常见现场描述、每天商品量、可接受的操作耗时与付费意愿。不能用模拟样本代替这些验证。
