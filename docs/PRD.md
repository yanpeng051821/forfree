## 问题与用户

面向在义乌等市场选品的外贸人员。照片、语音输入后的文字、供应商信息分散，回到办公室需要再次录入 Excel。目标是现场只记录一次，回去确认后即可导出。

## 主要流程

创建看货任务 → 选择或填写供应商 → 为一件商品拍摄多张照片 → 使用手机输入法输入整段描述 → 整理字段 → 确认、修改并保存 → 按任务搜索筛选、对比 → 导出带图或纯数据 Excel；现场可保存并继续记录下一件。

## 必须交付

- 原生微信小程序，未登录只显示独立登录入口，业务页面和底部导航不可进入；有效会话自动进入，登录成功进入自己的看货任务，退出/过期/401统一返回入口，保留按账号隔离的本机草稿；电脑通过导出的 Excel 整理，不另开发网页工作台。
- 看货任务创建、切换；日期条可滑动、选择、前后切换或日历跳转，支持查看全部任务。供应商在同一任务中可以复用。
- 收藏入口置于“我的”，选品顶部不设模式标签。商品图片直接点爱心，跨任务收藏可搜索、筛选、对比和导出。
- 个人选品评分1—5星，可取消，附文字评价；独立于采购事实与确认状态，可搜索，并进入对比和Excel。
- 商品录入：名称、货号、颜色、材质、尺寸、单件重量(g)、单价、币种、报价条款、起订量、每箱数量、外箱尺寸、单箱体积(m³)、大货交期(天)、供应商及联系方式、原始描述、备注、多张照片。
- 起订量与每箱数量分开；单件重量不从整箱重量推断。未知字段留空，不从商品外观猜尺寸、价格或重量。
- 保存商品前可编辑；支持修改和删除记录。
- 搜索整个任务内的商品、货号、供应商、联系方式、描述或备注；全部、待核对、已确认、待询价过滤。
- 选择两件商品并排核对采购条件；不跨币种自动比较报价。
- 按中国时间首次正式保存日回顾所有任务中的当天商品，支持搜索、状态筛选、修改、跨任务对比和当天 Excel 导出；修改不改变记录所属日。
- “我的”管理姓名、公司/商号、身份、电话、微信号、默认币种，保存到当前账号，版本冲突保留输入。语音使用手机键盘，不开发独立录音转写。
- 基础文字整理不需要凭据；可选服务端模型接口支持图片与文字整理。界面明确区分两种能力，不把规则处理标成模型识别。
- 小程序本机保留按账号/任务/商品隔离的草稿及持久照片；上传/识别失败时不清空输入，允许重试。
- 独立 Node 后端使用 SQLite 保存任务、商品版本、照片归属和幂等回执；图片存储可替换，当前持久化到服务器数据目录。
- Excel 导出每件商品一行，可选首图、照片数量、字段、供应商、原始描述和备注；小程序下载后打开或分享。完整图片在小程序中查看。
- 采购整理支持从现场选品生成人民币采购记录，或导入每商户一个明细区的多 sheet 采购表；箱数、每箱数量、采购单价、数量、金额、体积、图片、条码、运费和采购要求可核对。起订量不代表采购量，处理决定和商品资料确认分别管理；运费未知留空，零表示人工确认无额外运费。
- 在“我的 → 表格设置”一次保存当前账号的公司标准：中文/英文公司名、地址、联系方式和单据标题五行表头，逐行字体、字号、行高、加粗、对齐、显示与排序，最多3行补充表头；常用中文及英文数字字体、字段/商品/合计字号、列名/列宽/顺序/显示、最多8个可逐件填写的文本扩展列、打印版式。表头默认随商品列合并，隐藏列后仍按可见宽度换行，公式按字段标识引用。
- 后续采购整理使用已保存模板；旧记录主动应用最新模板且不丢已有扩展列数据。可从受支持的五行公司采购表读取模板建议，用户保存后生效。基础商品资料表导出保持原有字段，尚无多人共享公司模板或任意 Excel 样式/字段映射。
- 导入的原表保持 sheet、图片和格式，在后面追加汇总、明细、商户要求和核对记录；新增数量/金额/体积可重算。原取消范围、合计后商品和异常值不静默改成计入，留待人工处理。
- 不自动载入模拟数据，原全局示例seed入口移除；用户明确授权后可使用本机脚本添加标记演示数据，预先备份、重复执行不重复生成。
- 微信登录与用户隔离；所有读写和照片/导出由服务端授权，编辑版本冲突不可静默覆盖。

## 第一版边界

单实例原生小程序试用架构，包含微信身份和个人数据隔离；不包含团队共享权限、支付、客户 CRM、订单、报关或正式部署。发布仍需用户自己的 AppID、HTTPS 域名、微信隐私声明、持久卷与备份，并完成真机验收。多实例前迁移数据库、图片和共享限流。

小程序草稿不是完整离线同步：离线可保留输入及照片，保存到后端、图文整理与导出需要联网。本机 HTTP 仅用于微信开发工具，真机和发布须使用配置过合法域名的 HTTPS 服务。

不开发独立录音转写，不引入 Agent；复用手机输入法。

## 数据和准确性

每个商品属于一个任务；同一商品的照片共用记录 ID。保留原始输入。价格与重量必须有文字/标签依据；重量统一到克，但只有明确的单件单位才换算。币种采用个人资料的默认值（初始人民币），可切换；未经明确标记的整理结果需要用户确认。模型不能补猜未知信息。

## 验收

1. 创建任务后可录入多图商品，刷新页面后记录、图片和供应商均保留。
2. “杯子，红白两色，12元一个，100个起订，单个300克，每箱24个”得到明确字段；缺失的材质、尺寸留空。
3. “整箱重10公斤，每箱24个”不能被填到单件重量；起订量不误填24。
4. 修改、删除、搜索和状态筛选有效，任务间数据隔离。
5. 刷新未提交表单可以恢复文字和照片草稿，网络失败后仍能修改并重试。
6. 导出当前任务或当天记录 XLSX，全部/仅确认、带图/纯数据四种组合正确，字段、中文、数字和图片可用；删除后的记录不会导出。
7. 配置缺失时基础功能完整；外部模型超时、非成功响应、无效结构均给出可恢复错误。
8. 构建、类型检查、真实 HTTP API、客户端 mock 测试通过；九页原生编译与开发者工具布局已检查；真机完整流程需另行完成验收。
9. 午夜（中国时间）前后记录按正确日期归类，跨任务和分页不漏记录；导出的任务日期与记录日期分别列出。
10. 个人资料账号隔离、重试不重复、旧版本不覆盖；新建/连续录入使用个人币种，已有记录保留币种。
11. 未登录不可访问正式记录；两个账号的任务、商品、照片、提取和导出相互隔离；重复保存不新增，过期版本返回409且保留草稿。

12. 收藏按账号隔离，重试保持一致，旧版本冲突不覆盖；评分与个人评价保持采购确认状态，对比与导出内容正确。
13. 从“我的”进入独立收藏和历史记录，日期切换更新对应商品；选品顶部没有模式标签，仍可返回当前任务。
14. 导入多商户采购表保留原 sheet、图片、原值与待核对事项；逐件改采购数量、决定和运费后汇总正确，未知值不当作零。
15. 保存公司模板后新采购复用，重开设置仍保留；表头逐行样式、隐藏与排序、扩展列名/顺序/宽度进入导出，调整采购列顺序不改变计算含义。旧模板兼容，应用新模板保留旧扩展列已填数据，跨账号不可读取。
