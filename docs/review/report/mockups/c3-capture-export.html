对照 3 · 现场录入与 Excel 范围

左列：现状的录入页（约 18 个字段、两个悬浮圆钮、字段名混用英文 REF./QUANTITY）与导出页（只有格式和范围选项）。右列：正式方案的现场录入（系统相机、核心字段、文字保存按钮）与导出（日期、商户、缺项和十一列参考版式的局部缩略）。

现状记录商品：长表单，保存按钮悬浮遮挡内容
建议现场记录：核心字段在前，其余按需补充
现状导出：格式/范围两组分段器，缺少文件内容说明
建议商品 Excel：范围与缺项可见，不要求下单
验收：内容不丢、当前商户准确、复看少翻页、Excel范围/字段/图片一致。缺项允许导出；不承诺未经真机验证的动作数或保存耗时。
