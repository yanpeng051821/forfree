# 页面与交互

## 视觉方向

中文界面，暖白背景、深蓝绿色文字、绿色主按钮、少量橙色待补提示。信息密度适合手机，不做营销首页。桌面左侧任务导航，右侧商品列表；手机顶部切换任务，底部固定“记录商品”。

## 页面结构

- 空状态：创建看货任务为主入口，可主动体验模拟示例。
- 任务工作台：任务名称、市场、日期、商品数量；搜索和确认状态筛选；商品卡片展示首图、名称、供应商、价格、起订量和确认状态。
- 商品表单：供应商、多图拍摄/选择、整段描述和整理按钮；可展开全部字段；草稿本地保存；提交后关闭表单并刷新列表。
- 商品详情与修改：同一表单加载已有数据，展示所有照片、原始描述；确认和删除入口明确。
- 导出：当前任务内全部记录，包含未确认记录的状态列，不因搜索过滤而静默漏掉商品。

## 整理与错误

无模型配置显示“文字整理 · 照片仅存档”；有模型配置显示“图文整理”，告知照片与文字将发送到智能整理服务。规则与模型结果均需用户确认。用户可不整理而直接手工保存。

整理结果合并到尚未填写的字段；对冲突值不覆盖用户输入。文本或照片变化后，已确认状态需要再次确认。

保存、图片上传、识别、导出分别呈现错误，保留表单输入。没有数据时禁用导出。对删除操作进行确认。

## 草稿

使用 IndexedDB 存储一个当前未提交的采集/修改草稿（包括 Blob 图片），恢复前明确提示。成功保存或用户主动放弃时删除草稿；关闭表单保留草稿。私密模式或存储额度不足时明确提示草稿未能本地保存。
