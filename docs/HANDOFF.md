# 本地 Agent 接续

用户要求遵循“PRD → 交互/设计（审美可先简化）→ 开发 → 测试”，并在当前阶段先推送远程，切换本地 Agent 继续。

## 先读

`docs/PRD.md`、`docs/INTERACTION.md`、`docs/RESEARCH.md` 与本文件。使用现有 checkout；不需要创建 worktree。产品第一版不使用 Agent，也不开发独立录音转写，复用手机输入法语音输入。

## 已完成

- Next.js 16 / React 19 / TypeScript 工程，Node.js >=24。
- SQLite 持久化项目、商品和照片归属；本地图片存储，图片验证/转换，删除清理。
- 创建任务、商品新建/编辑/删除、照片读取、配置状态 API。
- 保守文字整理：价格、币种、起订量、每箱数量、明确单件重量、尺寸等；整箱重量不推断为单件重量。
- 可选服务端兼容模型接口（JSON 校验、超时和失败处理）；**没有真实外部模型调用验证**。
- 带首图、中文字段与确认状态的 XLSX 导出。
- 主动载入的模拟任务；素材明确为模拟商户、示意插画，不是真实网上采集样本。
- `src/components/product-editor.tsx`：商品表单组件，拍照/图片选择、文字整理、字段修改、保存/删除。
- `src/lib/draft.ts`：IndexedDB 草稿存储（包含图片 Blob）。组件与草稿代码目前只通过类型检查，**尚未挂到页面或经浏览器验收**。
- 7 项核心测试；生产 API 冒烟脚本。

## 下一步开发顺序

1. 添加 `src/app/layout.tsx`、`src/app/page.tsx`、基础样式和工作台组件。当前 `/` 是 404；不要把这份提交当成完成的 App。
2. 做任务创建/切换、商品列表、供应商复用、搜索、已确认/待补状态筛选、导出按钮及空状态。
3. 接入 `ProductEditor`；保存后刷新列表，编辑时传入已有商品，删除后刷新。
4. 初始化读取草稿并显示恢复/放弃入口；任务切换与编辑其他商品前避免静默覆盖草稿。检查草稿写入/删除的异步竞态。
5. 完成窄屏交互、弹窗焦点管理、键盘关闭、图片错误提示和保存/识别中状态。照片/描述变化后需要重新确认，已填写字段不得被整理结果无声覆盖。
6. 加浏览器端到端测试，运行手机尺寸的“任务 → 多图商品 → 整理 → 确认 → 刷新 → 修改 → 导出 → 删除”流程；验证草稿文字和 Blob 恢复、失败后数据保留。
7. 通过可用的 AnySearch/网页工具补齐公开资料调研；本云会话没有 AnySearch，直接访问三个参考网站均被出站代理 403 拦截。不要宣称已取得真实 Excel 或商品照片。
8. 用真实用户 Excel 和真实现场样本调整字段和导出布局。真实图文模型的准确率、耗时、费用需要后续单独验证。

## 验证命令

```bash
npm ci
npm run test
npm run typecheck
npm run build
npm run test:api
```

`test:api` 启动生产服务并使用隔离临时数据，不读取用户记录。开发数据留在 `.data/`；迁移本地无需复制云机器缓存或测试数据。Node 内置 SQLite 在部分 Node 版本可能给出实验性警告。

## 当前边界与限制

单个受信任团队试用架构，没有认证、访问隔离、对象存储和生产部署配置。网页 UI、完整离线同步、浏览器验收未完成。模型接口已实现但未接入真实凭据。基础文字整理是规则匹配，不应在 UI 中宣传为图片 AI 识别。
